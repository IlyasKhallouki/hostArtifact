# Artifact Publisher

Ask Claude to publish a complete HTML page for a client, update an existing page, add a password, or take a page offline. The plugin sends page HTML, client names, titles and access settings to the Google Cloud deployment operated by your administrator.

This directory is a template. Its connector URL is an example address. An administrator must deploy the server, fill in `infra/config.env`, and run `make plugin-zip`. Install the resulting ZIP and connect with an allowed Google account. Contact your deployment administrator for access or help.
