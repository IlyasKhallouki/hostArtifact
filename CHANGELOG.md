# Changelog

## 0.1.0

Initial public source release. Includes the MCP publishing tools, Google sign-in, a separate HTML viewer, version history, access controls, permission diagnostics, and custom-domain administration.

Deployment settings stay in an ignored local file. Plugin packaging writes a configured bundle to `dist/` and leaves the public template unchanged. OAuth storage supports both generated client IDs and Claude's URL-based client IDs.
